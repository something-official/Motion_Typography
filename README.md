# Motion Typography

A pointer, scroll, and bounded-noise typography study for learning readable motion.

## What this demonstrates

- Mapping continuous input into scale, tracking, rotation, and color
- Keeping animated type legible and centered
- Combining pointer, scroll, and deterministic noise
- Providing pause, reset, and local export controls
- Respecting reduced-motion preferences

## Run it

Open `index.html` in a modern browser. No npm, build step, or external dependency is required. Move over the canvas and scroll the page to change the specimen.

## Browser notes

The project does not request camera, microphone, or other permissions. Pointer and keyboard-accessible buttons provide the complete interaction.

## How to study this

Start with `render()`, identify each input-to-style mapping, then change one variable at a time. Keep the phrase readable while experimenting with scale and rotation.
